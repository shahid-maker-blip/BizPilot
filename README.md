# BizPilot – Smart Business Management System

BizPilot is a C++ desktop application designed to help small businesses manage daily operations.

## Features
- Customer management
- Quotations and invoices
- Payment tracking
- Financial reports
- Expense management
- SQLite database integration
- Invoice generation and HTML export
- Database integrity and backup utilities

## Technology Stack
- C++
- Dear ImGui
- SDL2
- SQLite
- Git

## Development Environment
- Windows
- MSYS2 UCRT64
- GCC / G++

## Project Structure
- `src/` – C++ application source code
- `assets/` – Application icons and visual assets
- `.gitignore` – Excluded files
